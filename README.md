# SMART-CONTRACT-FOR-NR-STUDENTS-RENTAL-HOUSING-SYSTEM

The "Smart Contract for NR Students Rental Housing System" proposes a solution for the problems that non-resident students face with the conventional house-rental system, which involves inefficiencies related to trust, legality, and procedures. Designing, developing, and testing a blockchain-based smart contract rental system is the task. This property rental system exploits Visual Studio for ASP.Net, SQL Server for database operations, and standard Web technologies for developing the front-end. This work shall incorporate smart contracts through Stratis blockchain technology as a means of guaranteeing transparency, security, and efficiency in the renting process. The methodology includes full-system coverage, development, testing, debugging, and versioning using Git, with Postman and Cirrus Core Private Net for testing. The findings establish its worth in effectively improving the transparency, security, and efficiency in house rentals for non-resident students. Specifically, the identified problems were all effectively addressed through the integration of Stratis blockchain and smart contracts, while also introducing new innovations to help enhance the whole rental experience. In this regard, this is a project of great importance to blockchain applications in real estate, as it will ensure that non-resident students at UiTM Shah Alam have a secure, transparent, and efficient renting platform, and it is envisioned to have broader applications in several areas.
